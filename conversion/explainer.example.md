# 해설 작성 지침

승인된 번역을 **왜 중요한지 풀어서 설명하는 글**로 재구성합니다. 개발자·생태계 참여자 대상 채널이 기준입니다.

- 사실 → 구조 → 의미 순서로 전개합니다. 결론만 던지지 않습니다.
- 구성 요소는 불릿으로 나열하되, 합쳐서 무엇이 되는지는 문장으로 마무리합니다.
- 읽는 사람은 기본 개념을 압니다. 기초 용어 정의로 분량을 채우지 않습니다.
- 원문에 없는 동작 원리를 추측해 서술하지 않습니다.
- 링크는 마케팅 페이지보다 문서·공식 발표를 우선합니다.

> 실제 팀 지침으로 교체해 쓰세요. 공지(`announcement.md`)는 해설성 문장을 지양하지만, 이 타입은 그것이 본론입니다.
